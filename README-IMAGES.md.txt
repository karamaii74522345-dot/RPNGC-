# RPNGC Image & Media Setup Guide

## Images to Add

Place the following images in the `images/` folder:

### **Image 1: Officers Training Group Photo**
- **Filename:** `image1.jpeg`
- **Usage:** 
  - Homepage background (fixed background)
  - Momase Region card
  - Background pattern throughout site
- **Recommended Size:** 1920x1080px (high resolution)
- **Display:** Police officers in ceremonial/training uniforms

### **Image 2: Police Station Building**
- **Filename:** `image2.jpeg`
- **Usage:**
  - Southern Region card image
  - Islands Region card image
  - Hero section overlay
- **Recommended Size:** 1200x800px
- **Display:** RPNGC police station exterior

### **Image 3: Police Officers Formation**
- **Filename:** `image3.jpeg`
- **Usage:**
  - Highlands Region card image
  - Page headers
  - Region gallery
- **Recommended Size:** 1200x800px
- **Display:** Police officers in organized formation/parade

### **Image 4: RPNGC Official Logo/Emblem**
- **Filename:** `logo-rpngc.png` or `image4.jpeg`
- **Usage:**
  - Navigation bar logo (50x50px)
  - Hero emblem section (200x200px)
  - Page branding
- **Recommended Size:** 512x512px (transparent PNG preferred)
- **Display:** Official RPNGC emblem with crown and bird
